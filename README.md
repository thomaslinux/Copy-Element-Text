# Installation

Download everything

## Chrome

``chrome://extensions/``

check Developer mode

load unpacked

Restart chrome

## Firefox

``about:debugging#/runtime/this-firefox``

replace manifest.json with firefox/manifest.json

load temporary module

(you'll have to do it every time you restart firefox)
